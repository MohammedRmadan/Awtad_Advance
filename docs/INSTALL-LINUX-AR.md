# تنصيب المنصة على خادم VPS لينكس – خطوة بخطوة

يناسب هذا الدليل خادمًا بنظام **Ubuntu 22.04 أو 24.04**، أو Debian 12، مع دخول SSH بصلاحية root. يتولى سكربت واحد التنصيب كله:
- Docker.
- قاعدة البيانات PostgreSQL.
- التطبيق.
- شهادة HTTPS المجانية من Let's Encrypt مع تجديدها التلقائي.
- الجدار الناري.
- النسخ الاحتياطي الليلي.

المدة المتوقعة: 15–20 دقيقة.

---

## قبل البدء

| المطلوب | التفاصيل |
|---|---|
| الخادم | 2 vCPU و4 GB RAM و40 GB تخزين على الأقل، داخل المملكة |
| عنوان IP | عنوان الخادم العام، تجده في لوحة مزوّد الخدمة |
| كلمة مرور root أو مفتاح SSH | من مزوّد الخدمة |
| نطاق (مستحسن) | مثل `bdhub.awtad.com.sa` |
| الملف | `awtad-bd-hub-v2.0.0.zip` |

**إعداد النطاق قبل التنصيب بنصف ساعة:** في لوحة DNS الخاصة بنطاق `awtad.com.sa`، أضف سجلًا من نوع **A**:
- الاسم: `bdhub`
- القيمة: عنوان IP الخادم

بدون نطاق تعمل المنصة عبر `http://عنوان-IP` بلا تشفير. يصلح هذا للتجربة فقط، ويمكنك إضافة النطاق لاحقًا (القسم 6).

---

## الخطوة 1: الاتصال بالخادم

**من ويندوز:** افتح PowerShell. **من ماك:** افتح Terminal. ثم نفّذ:
```bash
ssh root@عنوان-IP
```
اكتب `yes` عند السؤال الأول، ثم كلمة المرور. لا تظهر الأحرف أثناء كتابتها، وهذا طبيعي.

## الخطوة 2: رفع الملف إلى الخادم

افتح نافذة PowerShell **ثانية** على جهازك، وانتقل إلى المجلد الذي فيه الملف، ثم نفّذ:
```bash
scp awtad-bd-hub-v2.0.0.zip root@عنوان-IP:/opt/
```
يمكنك بدلًا من ذلك استخدام برنامج WinSCP أو FileZilla، ورفع الملف إلى `/opt` بالبروتوكول SFTP.

## الخطوة 3: فك الضغط

عد إلى نافذة الخادم ونفّذ:
```bash
apt-get update && apt-get install -y unzip
cd /opt && unzip awtad-bd-hub-v2.0.0.zip && cd bdhub
```
يُنشئ هذا المجلد `/opt/bdhub`. تأكد أن الأمر `ls` يُظهر الملف `docker-compose.yml`.

## الخطوة 4: التنصيب

```bash
sudo bash deploy/linux/install.sh
```
يسألك السكربت سؤالًا واحدًا: **Domain**.
- اكتب النطاق، مثل `bdhub.awtad.com.sa`.
- أو اضغط Enter للعمل بعنوان IP.

بعدها ينفّذ السكربت التالي تلقائيًا:
1. يثبّت Docker من موقعه الرسمي.
2. ينشئ ملف الإعدادات `.env`. يولّد فيه كلمة مرور عشوائية لقاعدة البيانات، ومفتاح جلسات، وكلمة مرور مؤقتة للمدير.
3. يفعّل الجدار الناري ويفتح المنافذ 22 و80 و443 فقط.
4. يبني النظام ويشغّله، ويحمّل البيانات الأولية (461 سجلًا).
5. يطبع في النهاية بيانات الدخول:

```
  Address:   https://bdhub.awtad.com.sa
  Username:  admin
  Password:  Awtad-xxxxxxxxxx-7     (temporary – you must change it at first sign-in)
```
تُحفظ هذه البيانات أيضًا في `/root/bdhub-first-login.txt`. احذف هذا الملف بعد أول دخول:
```bash
rm /root/bdhub-first-login.txt
```

> إذا ظهر تحذير أن DNS لا يشير إلى الخادم، فالسبب أن سجل A لم ينتشر بعد. يكمل النظام التنصيب، وتصدر الشهادة تلقائيًا خلال دقائق من تصحيح السجل.

## الخطوة 5: أول دخول وإضافة الفريق

1. افتح العنوان في المتصفح، وادخل باسم المستخدم `admin` وكلمة المرور المؤقتة.
2. اختر كلمة مرور جديدة: 10 أحرف على الأقل، وتحتوي على حروف وأرقام.
3. لإضافة كل زميل، افتح **المستخدمون** ثم **إضافة مستخدم**:
   - **اسم المستخدم:** أحرف إنجليزية صغيرة، مثل `ahmed.k`.
   - **الاسم:** الاسم الظاهر للزميل.
   - **الصلاحية:** الصلاحية المناسبة لدوره.
   - **الدور في الفريق:** دوره ضمن فريق تطوير الأعمال.
4. تظهر **كلمة مرور مؤقتة** مرة واحدة فقط. انسخها وسلّمها للزميل بطريقة آمنة، ويُطلب منه تغييرها عند أول دخول.
5. **إذا نسي مستخدم كلمة المرور:** في صفحة المستخدمين اضغط **إعادة تعيين كلمة المرور** مرتين للتأكيد، فتظهر كلمة مؤقتة جديدة.

أنشئ حسابًا شخصيًا لنفسك بصلاحية **مدير النظام**، واستخدمه بدل `admin`. يمكنك بعدها تعطيل `admin`.

## 6. أوامر الإدارة اليومية

نفّذ هذه الأوامر على الخادم بعد الاتصال عبر SSH:

| الأمر | الوظيفة |
|---|---|
| `bdhub status` | حالة الخدمات وصحة التطبيق |
| `bdhub logs` | سجل التطبيق المباشر (Ctrl+C للخروج). استخدم `bdhub logs caddy` لسجل HTTPS |
| `bdhub restart` | إعادة التشغيل، ويطبّق أي تعديل في `.env` |
| `bdhub backup` | نسخة احتياطية فورية في `/opt/bdhub/backups` |
| `bdhub backups` | قائمة النسخ الاحتياطية |
| `bdhub restore <ملف.dump> [ملف-المرفقات.tar.gz]` | استعادة نسخة، بعد أخذ نسخة أمان تلقائية |
| `bdhub reset-admin` | كلمة مرور مؤقتة جديدة لحساب `admin` إذا فُقد الدخول. أضف اسم مستخدم آخر بعده لإعادة تعيين حسابه |
| `bdhub update` | تحديث النظام لإصدار جديد |
| `bdhub psql` | فتح وحدة تحكم قاعدة البيانات |

### النسخ الاحتياطي
- تُحفظ نسخة تلقائية كل ليلة الساعة 02:15 في `/opt/bdhub/backups`:
  - `bdhub-التاريخ.dump`: قاعدة البيانات.
  - `uploads-التاريخ.tar.gz`: المرفقات.
- يحتفظ النظام بآخر 30 يومًا.
- **مهم:** انسخ هذا المجلد دوريًا إلى مكان آخر. من جهازك:
  ```bash
  scp -r root@عنوان-IP:/opt/bdhub/backups ./bdhub-backups
  ```
  أو فعّل ميزة اللقطات (Snapshots) في لوحة مزوّد الخدمة.

### التحديث لإصدار جديد
```bash
cd /opt && unzip -o awtad-bd-hub-vX.zip && bdhub update
```
- ملف `.env` والبيانات والنسخ الاحتياطية لا تتأثر.
- يأخذ الأمر نسخة احتياطية قبل التحديث.

### إضافة نطاق لاحقًا (إذا بدأت بعنوان IP)
1. أضف سجل A للنطاق يشير إلى الخادم.
2. نفّذ `nano /opt/bdhub/.env` وعدّل السطرين التاليين:
   ```
   BASE_URL=https://bdhub.awtad.com.sa
   SITE_ADDRESS=bdhub.awtad.com.sa
   ```
3. احفظ بـ Ctrl+O ثم Enter، واخرج بـ Ctrl+X.
4. نفّذ `bdhub restart`. تصدر الشهادة تلقائيًا خلال دقيقة.

### البريد اليومي (اختياري)
تعمل الإشعارات داخل المنصة (الجرس ومهامي) دون أي إعداد. لإرسال الملخص اليومي والأسبوعي بالبريد أيضًا:
1. عدّل في `.env`:
   - `MAIL_MODE=smtp`
   - بيانات خادم البريد: `SMTP_HOST` و`SMTP_PORT` و`SMTP_USER` و`SMTP_PASS` و`MAIL_FROM`.
2. نفّذ `bdhub restart`.
3. يحتاج المستخدم بريدًا مسجلًا في صفحة المستخدمين ليصله البريد.

## 7. الأمان المطبّق
- **كلمات المرور:** مخزّنة مشفّرة بخوارزمية scrypt، ولا يمكن لأحد قراءتها، بمن فيهم مدير النظام.
- **قفل الحساب:** يُقفل الحساب 15 دقيقة بعد 5 محاولات دخول خاطئة. يمكن للمدير فك القفل فورًا من صفحة المستخدمين.
- **الحسابات الجديدة:** تبدأ بكلمة مرور مؤقتة يجب تغييرها عند أول دخول.
- **إنهاء الجلسات:** تغيير كلمة المرور أو إعادة تعيينها ينهي جلسات المستخدم الأخرى، وتعطيل المستخدم يُخرجه فورًا.
- **الشبكة:**
  - HTTPS إجباري مع HSTS عند استخدام نطاق.
  - الجدار الناري يغلق كل المنافذ عدا 22 و80 و443.
  - قاعدة البيانات غير مكشوفة للإنترنت.
- **سجل التدقيق:** كل دخول ومحاولة فاشلة وتغيير كلمة مرور وتعديل سجل يظهر في **سجل النشاط**.

**توصيات إضافية:**
- غيّر كلمة مرور root للخادم.
- يفضّل الدخول إلى الخادم بمفتاح SSH بدل كلمة المرور.
- فعّل التحديثات الأمنية التلقائية:
  ```bash
  apt-get install -y unattended-upgrades && dpkg-reconfigure -plow unattended-upgrades
  ```

## 8. إذا واجهتك مشكلة

| العرض | الحل |
|---|---|
| المتصفح لا يفتح العنوان | `bdhub status`: يجب أن تكون الخدمات الأربع `running`. تحقق أيضًا من فتح المنفذين 80 و443 في جدار مزوّد الخدمة (Security Group) إن وُجد |
| تحذير شهادة أو الموقع لا يعمل بـ https | `bdhub logs caddy`: غالبًا سجل DNS لا يشير إلى الخادم بعد، أو المنفذ 80 مغلق لدى المزوّد |
| «انتهت صلاحية الصفحة» عند الدخول | العنوان المكتوب في المتصفح يختلف عن `BASE_URL` في `.env`، مثل الدخول بعنوان IP والإعداد بالنطاق. استخدم العنوان نفسه |
| نسيت كلمة مرور المدير | `bdhub reset-admin` |
| «غير متصل» أسفل القائمة | `bdhub logs` ثم `bdhub restart` |
| `Configuration errors` في السجل | متغير ناقص في `.env`، والرسالة تسمّيه |
